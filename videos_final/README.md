# Test videos — Indian traffic

Eight clips chosen from about 45 candidates. Each one was checked shot by shot: a steady camera, daylight,
clean decoding and plenty of two-wheelers. None of these videos was used to train any model. The Tirupati
clips come from the same police CCTV network as some triple-riding training clips, but they are different
videos. Audio has been removed. The clips are from YouTube, so use them for private testing only.

| File | What it tests | Notes |
|---|---|---|
| 01_intersection_signals_busy_1080p.mp4 | Everything: red light, helmet, triple riding, lanes | Fixed camera at a busy junction with signal heads in view. 39 s. |
| 02_bengaluru_junction_signal_1080p.mp4 | Helmet, triple riding, number plates, signals | Dashcam in a car waiting at the junction; riders pass close. 2 min. Burned-in captions at times. |
| 03_pune_talawade_chowk_1080p.mp4 | Red light, lanes, traffic flow | Elevated fixed view with a signal. Vehicles are far away, so most helmet calls will be "not sure". 56 s. |
| 04_red_light_jumpers_1080p.mp4 | Red light | Car waiting at a red light while riders cross it. 12.5 s. |
| 05_tirupati_cctv_junction_480p.mp4 | Helmet, triple riding | Police CCTV at a very busy junction. Plates are too small at 480p. 38 s. |
| 06_tirupati_cctv_triple_riding_480p.mp4 | Triple riding | Close CCTV views; the police's circles and logo are burned in. 67 s. |
| 07_tirupati_cctv_helmet_triple_480p.mp4 | Helmet, triple riding | Same kind of footage as 06. 92 s. |
| 08_tirupati_cctv_echallan_examples_480p.mp4 | Helmet, triple riding (many cameras) | About 25 short CCTV examples. Police-typed plate numbers are on screen, so don't use it to test plate reading. 3 min. |

Red light runs automatically on every upload (no camera setup). In 04 the light never turns green, so the
vehicles that drive through go to human review rather than straight to a challan. Speed cannot be
tested with these clips because the real distances are unknown.
